# v0.4.0 — Already have GAMMA on disk? Import it. And ModDB refusals stop being dead ends

## `import`: adopt an install you already have

Downloading 146 GiB you already own is absurd. Point the launcher at an
existing install and it adopts it:

```sh
stalker-gamma-linux import /path/to/your/gamma --dry-run   # see what it finds
stalker-gamma-linux import /path/to/your/gamma
```

It finds Anomaly and the Mod Organizer 2 instance by their markers, so it works
whatever the origin: a manual install, a folder shared with a Windows dual-boot,
or the [GOG one-click GAMMA that gets stuck in
Heroic](https://github.com/Heroic-Games-Launcher/HeroicGamesLauncher/issues/5063)
after downloading its 130 GB.

**Nothing is copied or moved.** If your folders aren't in the expected layout,
symlinks are created — reversible with a single `rm`. Only the two download
steps are marked done; `install --target …` then does the rest (ReShade removal,
Proton prefix, MO2 configuration, shortcut).

`doctor` now suggests it when it sees an install on disk it doesn't know about.

## A ModDB refusal is no longer a dead end

When ModDB refuses a download — a dead mirror, or a Cloudflare challenge, which
look identical from here — the install used to stop on a Python traceback, and
the advice was "retry", which is precisely what doesn't work.

You now get the only way out that actually works:

```
→ ModDB refused this download. Fetch this one file yourself:
   1. open https://www.moddb.com/mods/…/addons/…  in your browser;
   2. drop it in /your/install/gamma/downloads;
   3. run the same command again — files already there are not downloaded
      a second time.
```

In the launcher window, the error banner has an **Open page** button, so you
don't retype the URL by hand.

## Flat mode no longer costs you a second install

The fallback without Mod Organizer 2 (`play --flat`) merged Anomaly and the mods
by **copying** them — a full duplicate of your install, roughly 100 GiB. It now
merges with hardlinks: same tree, a few inodes.

One consequence worth knowing: the merged tree shares its files with your mods,
so edit mods under `gamma/mods/`, never inside `flat/`. Your settings and saves
(`appdata/`) are copied, not linked, so the game can never write back into your
Mod Organizer 2 install.

## Replay a single step

```sh
stalker-gamma-linux install --only prefix
```

Runs just that step, even if it's already marked done, and leaves the others
alone. For when something misbehaves and you (or an issue thread) need one step
rerun and its log — instead of replaying a 146 GiB pipeline.

## Also

- Secret scanning (gitleaks) now runs in CI, over the whole git history.
- `dx8vb` and `quartz` are settled: not needed. The first is the DirectX 8 type
  library *for Visual Basic* (the engine is C++ with its own DX8–DX11
  renderers), the second is the DirectShow runtime while Anomaly ships no video
  files at all. Six winetricks verbs remain, verified on a real install.

## Upgrading

```sh
curl -fsSL https://raw.githubusercontent.com/Fleorens/stalker-gamma-linux/main/install.sh | bash
```

or `./install.sh --no-launch` from an existing checkout. Your game, mods and
saves are untouched.
