# v0.5.0 — Import from the window, replay a single step, and package names that actually exist

## Importing an existing install no longer needs a terminal

`import` arrived in v0.4.0 as a command line only — which missed the point,
since the people it targets (a stuck GOG/Heroic install, a folder shared with a
Windows dual-boot) are exactly those who don't open a terminal.

It's now in the window: **menu → Import an existing install…**, pick the folder,
see what was found, confirm. The install target switches to what you adopted, so
the main button then finishes the setup — no re-download.

## The package names we told you to install were wrong

If your diagnostic said "7z missing" and you ran the command it gave you, it
failed. Verified against the real repositories on 2026-08-16:

- `p7zip` no longer exists on Fedora or Arch — it's `7zip` now. Both
  `dnf install p7zip p7zip-plugins` and `pacman -S p7zip` errored out.
- `libunrar5t64` does not exist on Debian 13. The name that works across
  Debian 12, Debian 13 and Ubuntu 24.04 is `libunrar5`.

Three of the four distributions the README promises were affected. A new CI job
now asks each distribution whether the names we display actually exist there, so
this rots loudly instead of silently.

## Replay a single step

```sh
stalker-gamma-linux install --only prefix
```

Runs that step even if it's already marked done, and leaves the others alone —
for when something misbehaves and you need one step rerun with its log, instead
of replaying a 146 GiB pipeline.

## Also

- Secret scanning (gitleaks) runs in CI over the whole git history.
- Arch CI containers now use `pacman -Syu` instead of `-Sy`: the partial upgrade
  really did produce a Python linked against a glibc missing from the image.
- Test isolation fix: logging configuration leaked from one test file to the
  next, which made a state test pass or fail depending on the pytest version.
- `packaging/aur/` now holds ready-to-publish PKGBUILDs (see its README).

## Upgrading

```sh
curl -fsSL https://raw.githubusercontent.com/Fleorens/stalker-gamma-linux/main/install.sh | bash
```

or `./install.sh --no-launch` from an existing checkout. Your game, mods and
saves are untouched.
