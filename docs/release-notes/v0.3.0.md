# v0.3.0 — GameMode, updates that don't touch your mod list, and a window that opens on Ubuntu

## Your mod list is no longer at risk when you check for updates

The most important fix in this release. **"Check for updates" used to run a full
reinstall** — and the upstream engine copies its own `modlist.txt` over yours as
part of that. On the maintainer's own install, that meant 757 customised lines
about to be replaced by the upstream 752, 149 disabled mods by 144, and 5
hand-added mods (including a translation patch) gone. One mislabelled click.

Now:

- **Checking is strictly read-only.** It compares a few dozen KB of definition
  files against GitHub and writes nothing — a test locks that contract by
  comparing the whole directory tree before and after. No network? You get
  "undetermined", never a false "up to date".
- **It reports the number Grokitach actually publishes**:
  *Your modpack is up to date (G.A.M.M.A definition 920)*, or
  *An update is available: definition 920 → 921*.
- **A real update backs up your profiles first**, to
  `<target>/backups/profiles-<date>`, before the engine runs — and if that copy
  fails, the update doesn't start. The confirmation spells out what is preserved
  (saves, in-game settings) and what isn't (the mod list).

`stalker-gamma-linux update --check` does the same read-only check from the CLI.

## GameMode, used automatically when you play

If [Feral GameMode](https://github.com/FeralInteractive/gamemode) is installed,
the game now launches through it: performance CPU governor and raised priorities
for the duration of the session, released when you quit. Nothing to configure,
and nothing breaks if GameMode isn't installed.

It applies to game launches only — never to downloads or to opening Mod
Organizer 2 on its own. Opt out with `play --no-gamemode` or the switch in
Preferences.

Two things the Diagnostic now explains, because they each cost hours:

- `gamemoded -s` answering "inactive" between sessions is **normal** — the
  daemon is D-Bus activated, there is no service to enable.
- On Fedora and Arch, the CPU-governor part is reserved to members of the
  `gamemode` group by a polkit rule, and **fails silently** otherwise. Diagnostic
  detects it and hands you the one-time `usermod` command.

## The launcher window now opens on Ubuntu 24.04

`Adw.Spinner` only exists in libadwaita 1.6; Ubuntu 24.04 ships 1.5, and the
home screen, the Diagnostic view and the progress view all failed to open —
including the very screen you need when something goes wrong. Fixed.

Debian 12 ships libadwaita **1.2**, which no reasonable patch will make
compatible. Instead of dying on an unreadable `AttributeError`, the Diagnostic
now says it plainly: the GUI needs libadwaita 1.5+, the CLI works regardless.

## Prerequisites are checked *before* you click Install

The install dialog now probes your system and shows a "System prerequisites"
line — checking, then either "all present" or the list of what's missing with a
button that opens the Diagnostic. The confirm button stays inactive until that
probe returns: offering a 146 GiB download before knowing whether `7z` is even
installed was exactly the problem.

Errors also get a banner at the top of the progress view, with the fix and a
Copy button, instead of scrolling away in hundreds of lines of engine output.

## Uninstall, cancel, and know what you're running

- **Uninstall** is in the window's menu now, with a confirmation that literally
  lists what will disappear — and reminds you your game data isn't included.
- **Play and Open MO2 are cancellable.** If MO2 never hands back control, you no
  longer have to kill the window.
- **The installed version appears in About**, so an issue report can say which
  build it's about.

## Upgrading

```sh
curl -fsSL https://raw.githubusercontent.com/Fleorens/stalker-gamma-linux/main/install.sh | bash
```

or `./install.sh --no-launch` from an existing checkout. Your game, mods and
saves are untouched.

## Good to know

- Installing needs ≈ 160 GiB free (17 base game + 83 modpack + 46 download
  cache, plus extraction margin).
- The GUI needs GTK4 + libadwaita 1.5+. The CLI has no such requirement.
- Hit a problem? `stalker-gamma-linux doctor --report` writes a single file with
  your prerequisites, prefix state and the tail of the log, paths anonymised —
  attach it to the issue and skip the back-and-forth.
